Uniffy puts notes, files, chat, projects, calendar, and AI agents in one workspace. Every piece of content has a URN so you can reference anything from anywhere with `@` mentions.

## What is in these docs

- **[User Guide](/docs/user/)** — for everyone using Uniffy day to day. Notes, files, chat, mentions, agents, calendar.
- **[Administration Guide](/docs/administration/)** — for org owners and admins. Members, permissions, SSO, audit, encryption.
- **[Deployment Guide](/docs/deployment/)** — for operators self-hosting Uniffy. Install, configure, upgrade, back up.

## Where to start

If you just signed up: jump into the product. The app is the best place to learn.

If you are evaluating Uniffy for your team: see the comparison and pricing on [uniffy.io](/).

If you are self-hosting: start with the [Deployment Guide](/docs/deployment/).
